# Phone Calls: Parasite Eve's own calls
#
# After Aya saves at a phone, the game asks "Stay on the line?". On Yes, one of these calls plays,
# one dialogue box per line. This file is plain text: change any line, add calls, save, then
# F1 > Phone Calls > Reload calls (or restart the game). Mistakes are listed in pe_mods.log with
# the file and line; a call with a mistake is left out, the rest still load.
#
# Where this file lives: in the game, a copy is in the "pe_calls" folder beside your preferences
# (F1 > Phone Calls > Open calls folder). Edit that copy. Any other .txt file you put in that
# folder is loaded too, so your own calls can live in a file of their own (mycalls.txt). Delete
# pe1.txt there to go back to the calls built into the game.
#
# ---- How a call is written ----
#
#   [pe1/pizza]                    the call's key, in square brackets: pack/name.
#                                  Saves remember calls by key, so don't rename one once it's played.
#                                  Use your own pack name for your calls: [mine/landlord2]
#   caller = Tony's Pizza          the name shown for the other side
#   tone = funny                   serious or funny (F1 > Call tone picks which can come up)
#   day = 1                        story day it can play on: 1 to 6, a range 2-5, or any
#   them: Tony's Pizza, how can I help?      a line the caller says
#   aya: Can you deliver to Carnegie Hall?   a line Aya says (shown with the name the player gave her)
#
# Optional settings (the default is in brackets):
#
#   weight = 2                     how often it comes up next to the others [1]
#   once = yes                     at most once per playthrough [no]
#   rooms = 32 75                  only at these phones (room numbers, see below) [any phone]
#   priority = 10                  above 0: plays first at its phones until heard, before any random call [0]
#   after = pe1/other              only once that call has been heard [-]
#   story = 0x80-0xE8              finer than day: the story value range (script variable 74) [any]
#
# Text: letters, digits, spaces and . , : ! ? ' - + * % / only (the game's font has nothing
# else). {name} is Aya's name as the player typed it. Write a line as long as you like: it wraps
# to the box, three lines a box, and runs on into another box if it has to.
# F1 > Phone Calls > Writing calls: Try call picks any call by its key and Play it now plays it
# (no save needed); Check calls measures every call with the game's font.
#
# Phone rooms: 20, 42, 59, 64, 75, 87, 97, 99, 112, 126, 138, 154, 163, 176, 184, 195, 196, 237,
# 238, 266, 276, 325, 340, and 32 (the Day 1 sewer's emergency phone). The room of the last phone
# you used is shown at F1 > Phone Calls > Last phone.
#
# Keep it spoiler-safe: nothing from after the call's day.
