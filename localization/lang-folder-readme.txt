Language packs go in this folder.

1. Put a .pelang file here.
2. Start the game. The first time it finds language packs it asks which language to use.
3. To change the language later: press F1, open Language, pick one, then restart the game.

The game comes with no translations of its own. A pack only changes the text and the pictures
with words; it does not need "All mods" to be on.
